SEAT RESERVATION SERVICE - LOCAL RUN & VERIFICATION GUIDE
========================================================

Purpose
-------
This guide is for a reviewer who has cloned the repository and wants to:

1. Build the project from a clean checkout.
2. Run the complete application locally.
3. Verify PostgreSQL, Redis, Flyway, health probes, metrics and logs.
4. Create users and an admin.
5. Create fresh shows.
6. Verify normal reservations, idempotency, cancellation and reconciliation.
7. Reproduce the concurrency/load tests that were used during development.
8. Verify the PostgreSQL correctness boundary even when Redis is unavailable.

Repository:
https://github.com/yashupadhyay266/seat-reservation-service

Live URL:
https://seat-reservation-service-2kyt.onrender.com

See the downloadable copy shared in this chat for the complete step-by-step commands.

Key local verification path:
- mvn clean package -DskipTests
- docker compose -f .\docker\docker-compose.full.yml up --build -d
- verify postgres / redis / app1 / app2 / gateway
- verify readiness, liveness, Prometheus and X-Request-ID
- register a local user and promote it to ADMIN in local PostgreSQL
- create fresh shows
- run single reservation, idempotency, multi-seat, cancellation and rebooking checks
- run hot-seat-500.js
- run per-user-limit.js
- run cancel-5000.js
- optionally run burst-20k.js
- stop Redis and repeat the hot-seat test to prove PostgreSQL correctness
- run the SQL duplicate-seat verification query
- inspect structured JSON logs and Prometheus metrics
